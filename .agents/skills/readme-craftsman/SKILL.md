# README Craftsman Skill

This skill guides the creation of high-impact, beautifully styled GitHub README documentation.

## Core Directives

### 1. Header & Badges
- Include a descriptive title with an emoji.
- Add badges for Status, License, Web Standards, Technologies, and WCAG Accessibility using shields.io.
- Include a brief and engaging pitch (1-2 sentences).

### 2. Visual Previews & GIFs
- Present clean previews of the app (Light & Dark Mode, key interactions).

### 3. Feature Highlights & Architecture
- Use structured tables or bullet lists detailing user-facing features and technical implementations.
- Present directory structure using ASCII trees.

### 4. Step-by-Step Local Setup
- Clear and concise instructions to clone, run, and test the project.

### 5. Quality & Accessibility Standards
- Highlight OWASP security practices, WCAG AA compliance, and clean code patterns.
